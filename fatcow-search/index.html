FatCow Icons, also known as Farm-Fresh Web Icons, is a set of 3,926 hand-crafted pixel art icons created by FatCow Web Hosting in the late 2000s.

Originally designed for web applications and software interfaces, the set remains a go-to resource for prototyping, internal tools, and retro-styled projects.

The collection is also available on GitHub (archived) and cataloged on Wikimedia Commons.
